# Video Demonstration Submission Instructions

This directory is reserved for the demonstration video recording of the **AUTOSAR HLD Document Analysis Assistant**.

---

## Instructions for Student:
1. Review the full narration script provided in `Documentation/Video_Demonstration_Script.md`.
2. Launch the Streamlit application using:
   ```powershell
   streamlit run app.py
   ```
3. Record a 5–10 minute video demonstration capturing:
   - System Overview & Home dashboard
   - Document upload and ingestion
   - Processing status and chunk inspector
   - Grounded Q&A with citations and out-of-domain abstention
   - Architectural entity extraction and export
   - Revision comparison between v1.0 and v2.0
   - Potential issue and inconsistency detection
   - Evaluation dashboard showing real benchmark results
4. Save the finalized video file directly into this folder with the name:
   `Demonstration_Video.mp4`

*(Note: In accordance with academic submission integrity guidelines, no placeholder video file has been forged. The student must record and place their actual video demonstration file here prior to final submission.)*
